### 2. Automating Learning Folder Management on Google Drive
`2025 – Present` · Research project · Role: Developer · 🏆 **Third Prize, Faculty-level Scientific Research 2026**

Automates the creation, control, and synchronization of learning-material structures on Google Drive.

- Built an **ETL pipeline** that generates Google Forms dynamically from spreadsheet configuration and syncs responses into a central Google Sheet.
- Designed a horizontally scalable **Rule Engine** to expand the database structure by file count, set submission deadlines, and restrict file formats per project.
- Developed **security modules** to lock/unlock sheets automatically against unauthorized edits, with **Role-Based Access Control (RBAC)** to protect academic data.
- Implemented a **Depth-First Search (DFS)** algorithm to serialize a designed folder tree into a flat dataset, enabling bulk creation of hierarchical folder structures.

**Tech:** `Google Apps Script` `JavaScript` `Google Drive` `Google Sheets` `Google Forms` `ETL` `RBAC` `DFS`
